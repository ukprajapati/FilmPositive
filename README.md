# FilmPositive

FilmPositive is a standalone Windows application for converting
camera-scanned color and black-and-white film negatives.

## Features

- GPU-accelerated negative conversion
- Film-base sampling and adjustable inversion
- Cropping, rotation, color adjustments, and sharpening
- Per-frame editing and roll workflows
- TIFF and JPEG export

## Download

Open Releases and download the Windows x64 Setup installer.

No Python installation or administrator access is required.

## Status

Version 0.8.0 is available for testing.
The Windows installer is currently unsigned.
